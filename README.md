# OMNIfood Project

## Project Overview
OMNIfood is an AI-powered food subscription service that makes it easy to enjoy healthy and delicious meals at home. Our smart algorithm creates personalized weekly meal plans based on your preferences and nutritional needs.

## Features

### How It Works

#### Step 1: Tell us what you like
- Complete a simple preference survey
- Our AI learns your taste preferences and dietary requirements
- Get matched with meals from our database of 5,000+ recipes

#### Step 2: Approve your weekly plan
- Receive a personalized meal plan every Monday
- Review and customize your selections
- Swap or skip any meal you don't like
- 20+ different cuisine options available

#### Step 3: Receive meals at convenient time
- Fresh ingredients delivered daily between 8am-12pm
- Insulated packaging maintains perfect temperature
- Easy-to-follow recipe cards included
- Free delivery for all subscription plans

## Installation & Setup

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local server for development (optional)

### Running the Project
1. Clone or download the project files
2. Open `index.html` in your web browser
3. For local development, use a local server:
   ```bash
   python -m http.server 8000
   ```
